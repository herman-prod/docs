## Contributors

AARM is an open specification. We welcome contributions from security researchers, agent framework developers, and enterprise practitioners.

<Note>
Want to contribute? Open an issue or pull request on the [GitHub repository](https://github.com/aarm-spec/aarm).
</Note>

### How to Contribute

| Contribution Type | How |
|-------------------|-----|
| Report issues | Open a GitHub issue |
| Suggest improvements | Submit a pull request |
| Share implementation notes | Add to the Guides section |
| Propose new patterns | Contribute to Patterns |
| Review and feedback | Comment on open PRs |
